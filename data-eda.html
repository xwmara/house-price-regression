Data

The data describe 2,930 residential property sales in Ames, Iowa, between 2006 and 2010 (De Cock, 2011), in the processed version of the AmesHousing R package. The data are cross-sectional: each row is one sale. Source, terms of use and the full data dictionary are in the data README.

Out of 81 available columns, the analysis keeps the sale price and nine candidate predictors that describe the size, quality, age and location of a house:

Variable Description Unit
Sale_Price Sale price (dependent variable) US dollars
Gr_Liv_Area Above-ground living area square feet
Overall_Qual Overall material and finish quality, rated by the assessor ordinal, 10 levels
Garage_Cars Garage capacity number of cars
Full_Bath Full bathrooms above ground count
Bedroom_AbvGr Bedrooms above ground count
TotRms_AbvGrd Total rooms above ground, excluding bathrooms count
Lot_Area Lot size square feet
Year_Built Original construction year year
Neighborhood Neighborhood within Ames city limits 28 categories

Train/test split

Code 
split_quantiles <- rbind(
  Train = quantile(train$Sale_Price, c(0.1, 0.25, 0.5, 0.75, 0.9)),
  Test = quantile(test$Sale_Price, c(0.1, 0.25, 0.5, 0.75, 0.9))
)

The data are split into a training set (2,049 houses, 70%) and a test set (881 houses, 30%). Models are estimated on the training set only; the test set is kept aside to measure how well they predict houses they have not seen.

The split is stratified by log price: houses are grouped into price quartiles and each quartile is split 70/30. This keeps the price distribution similar in both sets, so the test set does not end up with mostly cheap or mostly expensive houses, which would distort the evaluation.

Principal component analysis

Code 
pca_model <- prcomp(ml_scaled, center = FALSE, scale. = FALSE)
# The sign of a component is arbitrary. Flip PC1 so that higher scores mean
# larger, better houses.
pca_model$rotation[, 1] <- -pca_model$rotation[, 1]
pca_model$x[, 1] <- -pca_model$x[, 1]

var_share <- pca_model$sdev^2 / sum(pca_model$sdev^2)
cum_share <- cumsum(var_share)
loading <- function(var, pc) fmt_num(pca_model$rotation[var, pc], 2)

ggplot(data.frame(pc = seq_along(var_share), share = var_share),
       aes(x = pc, y = share)) +
  geom_col(fill = "steelblue") +
  geom_line(aes(y = cumsum(share))) +
  geom_point(aes(y = cumsum(share))) +

  scale_y_continuous(labels = scales::label_percent()) +
  labs(x = NULL, y = "Variance explained (bars: each, line: cumulative)")

The first two principal components explain 68% of the total variation in the seven predictors, and the first three explain 81%. Seven correlated variables can be summarized by a few components, which confirms the strong correlations between the predictors.

Code 
knitr::kable(pca_model$rotation[, 1:3], digits = 2)

  • PC2 (18%) contrasts large houses with many rooms and big lots (living area 0.35, rooms 0.47, lot 0.45) with newer, higher-quality houses (year built -0.57, quality -0.27).
  • PC3 (13%) is dominated by lot area (-0.86).
Code 
arrow_scale <- 8  # loadings are lengthened so the arrows are readable
loadings_df <- data.frame(var = rownames(pca_model$rotation),
                          PC1 = pca_model$rotation[, 1] * arrow_scale,
                          PC2 = pca_model$rotation[, 2] * arrow_scale)

# Place labels to the right of the arrow tips, with a minimum vertical gap so
# that arrows pointing in almost the same direction do not overlap.
loadings_df <- loadings_df[order(loadings_df$PC2), ]
loadings_df$label_y <- loadings_df$PC2
for (i in seq_len(nrow(loadings_df))[-1]) {
  loadings_df$label_y[i] <- max(loadings_df$label_y[i], loadings_df$label_y[i - 1] + 0.6)
}

ggplot(data.frame(pca_model$x[, 1:2], segment = houses$segment),
       aes(x = PC1, y = PC2)) +
  geom_point(aes(color = segment), alpha = 0.3) +
  geom_segment(data = loadings_df, aes(x = 0, y = 0, xend = PC1, yend = PC2),
               arrow = arrow(length = unit(0.2, "cm"))) +
  geom_label(data = loadings_df, aes(x = PC1 + 0.2, y = label_y, label = var),
             hjust = 0, size = 3, alpha = 0.8) +
  labs(x = paste0("PC1 (", fmt_pct(var_share[1], 0), ")"),
       y = paste0("PC2 (", fmt_pct(var_share[2], 0), ")"),
       color = "Segment")

All arrows point to the right, in the direction of PC1, which confirms the positive correlations between the size and quality indicators. Along PC2 they split into two groups: size variables (living area, rooms, lot area) point up, while quality, garage capacity and construction year point down.

The segments line up along PC1: the Budget segment sits at low PC1 scores and the Premium segment at the highest ones. The Mid-range segment sits lower on PC2 than the Premium segment: on average its houses are newer (built around 1994 versus 1983) but much smaller.

data are cross-sectional: each row is one sale. Source, terms of use and the

```{r}
  geom_point(aes(y = cumsum(share))) +
  scale_x_continuous(breaks = seq_along(var_share), labels = paste0("PC", seq_along(var_share))) +
  scale_y_continuous(labels = scales::label_percent()) +
  labs(x = NULL, y = "Variance explained (bars: each, line: cumulative)")
```

The first two principal components explain `r fmt_pct(cum_share[2], 0)` of
the total variation in the seven predictors, and the first three explain
`r fmt_pct(cum_share[3], 0)`. Seven correlated variables can be summarized by
a few components, which confirms the strong correlations between the
predictors.

```{r}

#| tbl-cap: "Loadings of the first three principal components"

```

- **PC1** (`r fmt_pct(var_share[1], 0)` of the variance) has positive loadings
  on all variables: it measures the overall size and quality of a house.
- **PC2** (`r fmt_pct(var_share[2], 0)`) contrasts large houses with many
  rooms and big lots (living area `r loading("Gr_Liv_Area", 2)`, rooms
  `r loading("TotRms_AbvGrd", 2)`, lot `r loading("Lot_Area", 2)`) with newer,
  higher-quality houses (year built `r loading("Year_Built", 2)`, quality
  `r loading("Overall_Qual", 2)`).
- **PC3** (`r fmt_pct(var_share[3], 0)`) is dominated by lot area
  (`r loading("Lot_Area", 3)`).

All arrows point to the right, in the direction of PC1, which confirms the
positive correlations between the size and quality indicators. Along PC2 they
split into two groups: size variables (living area, rooms, lot area) point
up, while quality, garage capacity and construction year point down.

The segments line up along PC1: the Budget segment sits at low PC1 scores and
the Premium segment at the highest ones. The Mid-range segment sits lower on
PC2 than the Premium segment: on average its houses are newer (built around
`r round(seg("Mid-range", "Mean year built"))` versus
`r round(seg("Premium", "Mean year built"))`) but much smaller.
